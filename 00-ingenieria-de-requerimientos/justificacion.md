# Justificación

El proyecto se justifica desde tres ángulos:

**Tecnológico:** centraliza la información del negocio en una base de datos,
eliminando el registro manual disperso en cuadernos o chats.

**Comercial:** un chatbot disponible en todo momento reduce el tiempo de respuesta
a los clientes y libera tiempo del personal para la producción.

**Administrativo:** el informe mensual automatizado (personas atendidas,
calificación promedio y sugerencias) permite a la administración tomar decisiones
basadas en datos reales y no en percepciones.

Adicionalmente, al tratarse de una empresa que recopila datos personales de
distintos niveles de sensibilidad, el proyecto refuerza el cumplimiento de la
Ley 1581 de 2012 (Habeas Data) mediante el diseño de una base de datos segregada.
