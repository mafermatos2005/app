# Casos de uso (resumen)

| Caso de uso                     | Actor principal | Descripción breve                                      |
|----------------------------------|------------------|----------------------------------------------------------|
| CU01 - Consultar catálogo        | Cliente          | El cliente visualiza los sabores disponibles y precios.  |
| CU02 - Registrarse                | Cliente          | El cliente diligencia el formulario y autoriza el uso de sus datos. |
| CU03 - Conversar con el chatbot   | Cliente          | El cliente hace preguntas y recibe respuestas automáticas.|
| CU04 - Calificar atención         | Cliente          | El cliente califica la atención del chatbot de 1 a 5.     |
| CU05 - Generar informe mensual    | Administrador    | El administrador solicita el informe y visualiza métricas.|
| CU06 - Cambiar idioma             | Cliente          | El cliente alterna la interfaz entre español e inglés.    |
