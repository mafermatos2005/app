# CASOS DE USO

## CU-01 – Iniciar sesión

Actor principal: Usuario

Descripción: Permite al usuario autenticarse para ingresar al sistema.

## CU-02 – Gestionar repositorio

Actor principal: Administrador

Descripción: Permite crear, modificar y administrar repositorios documentales.

## CU-03 – Cargar documento

Actor principal: Usuario

Descripción: Permite cargar un documento al sistema.

## CU-04 – Procesar documento

Actor principal: Sistema de IA

Descripción: Extrae y analiza el contenido del documento.

## CU-05 – Clasificar documento

Actor principal: Sistema de IA

Descripción: Asigna una categoría al documento.

## CU-06 – Generar resumen

Actor principal: Sistema de IA

Descripción: Genera un resumen automático.

## CU-07 – Extraer información

Actor principal: Sistema de IA

Descripción: Identifica información relevante dentro del documento.

## CU-08 – Buscar información

Actor principal: Usuario

Descripción: Permite buscar información dentro del repositorio.

## CU-09 – Consultar mediante lenguaje natural

Actor principal: Usuario

Descripción: Permite realizar preguntas sobre los documentos.

## CU-10 – Consultar dashboard

Actor principal: Administrador

Descripción: Permite consultar indicadores del sistema.
