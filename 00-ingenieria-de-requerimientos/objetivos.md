# Objetivos

## Objetivo general
Desarrollar una plataforma web para Dulce Diva que gestione clientes, pedidos y
atención al cliente mediante un chatbot, conectada a una base de datos, con un
módulo de informes mensuales para la administración.

## Objetivos específicos
1. Diseñar una página web informativa y comercial para los productos de Dulce Diva.
2. Implementar un formulario de registro de clientes que clasifique los datos según
   su nivel de sensibilidad (público, semiprivado, privado, sensible).
3. Desarrollar un chatbot de atención al cliente disponible en la página.
4. Conectar el sitio a una base de datos relacional para persistir clientes,
   pedidos y atenciones.
5. Generar un informe mensual con personas atendidas, calificación promedio y
   sugerencias automáticas para la administración.
6. Incluir un selector de idioma español/inglés en la interfaz.
