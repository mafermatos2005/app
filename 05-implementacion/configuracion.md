# Configuración

**Base de datos:** SQLite. El archivo dulcediva.db se genera automáticamente
en backend/db/ la primera vez que se ejecuta server.js; no requiere instalar
un motor de base de datos aparte.

**Ruta del backend en el frontend:** editar la constante API_URL en
frontend/script.js si el servidor corre en un puerto distinto a 3000.
