# FLUJO DE PROCESAMIENTO DOCUMENTAL

1. El usuario carga un documento.
2. El sistema valida el formato.
3. El documento es almacenado.
4. Se extrae su contenido.
5. El contenido es enviado al componente de Inteligencia Artificial.
6. La IA analiza el contenido.
7. Se realiza la clasificación.
8. Se genera el resumen.
9. Se extrae información relevante.
10. Los resultados son almacenados.
11. El usuario puede buscar información.
12. El usuario puede realizar preguntas mediante lenguaje natural.
13. El sistema genera una respuesta basada en la información procesada.
