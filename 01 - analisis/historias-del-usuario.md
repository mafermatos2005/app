# HISTORIAS DE USUARIO

## HU-01 – Iniciar sesión

Como usuario, quiero iniciar sesión en el sistema para acceder de manera segura a mis documentos.

### Criterios de aceptación

- El usuario debe ingresar sus credenciales.
- El sistema debe validar las credenciales.
- Si son correctas, debe permitir el acceso.
- Si son incorrectas, debe mostrar un mensaje de error.

---

## HU-02 – Cargar documento

Como usuario, quiero cargar un documento para almacenarlo en el repositorio.

### Criterios de aceptación

- El sistema debe permitir seleccionar un archivo.
- Debe validar el formato.
- Debe almacenar el documento.
- Debe iniciar su procesamiento.

---

## HU-03 – Clasificar documento

Como usuario, quiero que el sistema clasifique automáticamente un documento para organizar mejor la información.

### Criterios de aceptación

- El documento debe ser procesado.
- La IA debe analizar su contenido.
- El sistema debe asignar una categoría.

---

## HU-04 – Generar resumen

Como usuario, quiero obtener un resumen de un documento para comprender rápidamente su contenido.

### Criterios de aceptación

- El documento debe haber sido procesado.
- La IA debe generar un resumen.
- El resumen debe quedar asociado al documento.

---

## HU-05 – Extraer información

Como usuario, quiero que el sistema extraiga información relevante de los documentos para evitar realizarlo manualmente.

### Criterios de aceptación

- El sistema debe identificar información relevante.
- Debe mostrar los datos extraídos.
- Los resultados deben relacionarse con el documento.

---

## HU-06 – Buscar documentos

Como usuario, quiero buscar información dentro de los documentos para encontrar rápidamente contenido específico.

### Criterios de aceptación

- El usuario debe ingresar una búsqueda.
- El sistema debe consultar el contenido procesado.
- Debe mostrar los documentos relacionados.

---

## HU-07 – Preguntar a la IA

Como usuario, quiero realizar preguntas en lenguaje natural sobre los documentos para obtener respuestas basadas en su contenido.

### Criterios de aceptación

- El usuario debe escribir una pregunta.
- El sistema debe consultar la información disponible.
- La IA debe generar una respuesta.
- La respuesta debe relacionarse con los documentos.

---

## HU-08 – Consultar dashboard

Como administrador, quiero visualizar indicadores del repositorio para conocer el estado de la información almacenada.

### Criterios de aceptación

- Deben mostrarse indicadores.
- Los datos deben corresponder al repositorio.
- Los resultados deben actualizarse según la información registrada.
