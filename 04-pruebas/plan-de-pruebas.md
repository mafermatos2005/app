# PLAN DE PRUEBAS

## Objetivo

Verificar que el Sistema Inteligente de Gestión y Análisis Documental cumpla con los requerimientos establecidos.

## Alcance

Se probarán:

- Autenticación.
- Carga de documentos.
- Validación de formatos.
- Procesamiento documental.
- Clasificación.
- Resumen.
- Extracción.
- Búsqueda.
- Consultas mediante IA.
- Dashboard.
- Seguridad.
- Manejo de errores.

## Tipos de pruebas

- Pruebas funcionales.
- Pruebas de validación.
- Pruebas de Inteligencia Artificial.
- Pruebas de seguridad.
- Pruebas de errores.
- Pruebas de integración.
